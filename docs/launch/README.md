## Rules learned the hard way
- Every post leads with an image, then explains with more images. No walls of text.
- No em dashes; plain punctuation, so it does not read as generated text.
- Images must be the HD versions (scenes rendered at 128 px icons). Medium stores the original and lets
  readers zoom; dev.to caps displayed images at 800 px.
- On LinkedIn, bold comes from Unicode maths-bold characters, generated with a mapping function and
  round-tripped back to ASCII to check for typos. Blank lines need a zero-width space or LinkedIn eats them.
- Read back the rendered page before and after publishing.
