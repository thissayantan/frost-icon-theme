# Architecture

```
src/<context>/<name>.svg ──┐
src/<context>/<name>.<size>.svg (optional hand-tuned) ──┤
src/aliases.json ──────────┤        tools/build.ts
docs/DESIGN.md tokens ─────┘   ┌─────────────────────────────────────┐
                               │ 1. lint (layer ids, palette, grid)  │
                               │ 2. derive size variant (drop layers,│
                               │    scale blur σ)                    │
                               │ 3. render with resvg @1x and @2x    │
                               │ 4. optimise PNG (sharp, zlib 9)     │
                               │ 5. symlink aliases                  │
                               │ 6. write index.theme                │
                               │ 7. gtk-update-icon-cache            │
                               └─────────────────────────────────────┘
                                            │
                              dist/Frost/{16,22,24,32,48,64,96,128,256}x…/{context}/*.png
                              dist/Frost/…@2x/…
                              dist/Frost/index.theme  (Inherits=Papirus,Adwaita,hicolor)
                              dist/preview/sheet.png
```

Toolchain: **Bun + TypeScript** for tools (owner already uses Bun). Rendering with
`@resvg/resvg-js` (reference-grade renderer, full filter support, no system deps). SVG hygiene with
`svgo` (source-preserving config: keep ids, keep filters). Python only for `tools/lookup.py`, which
asks real GTK which file it would load.

## Decisions (ADRs)

### ADR-001 — Ship PNG, author SVG
**Context.** The glass look needs Gaussian blur (`frost`, `glow`, `shadow`). Renderers differ:
GTK 4.22 still resolves named theme icons through its older path rather than the new GtkSvg
engine, GTK3 goes through gdk-pixbuf/librsvg, Qt's QtSvg implements SVG Tiny (no filters at all),
and GNOME Shell has its own path. A filter-heavy SVG in `dist/` would look different — or broken — per toolkit.
**Decision.** Sources are SVG with filters; the theme ships pre-rendered PNGs at every size
(`Type=Fixed`) plus `@2x` (`Scale=2`). Output is identical everywhere.
**Cost.** Larger install (budget: < 25 MB for v0.1; < 40 MB from v0.2, see ADR-006). Re-evaluate when GtkSvg handles theme icons.

### ADR-002 — Overlay theme, not a full theme
Ship only what Frost redraws; everything else inherits `Papirus, Adwaita, hicolor`.
Keeps scope honest and matches the owner's setup. README states Papirus is recommended.

### ADR-003 — Layer ids drive size variants
One source per icon; small sizes are derived by removing layers (`DESIGN.md §4`). Hand-tuned
`<name>.<size>.svg` overrides exist for the cases derivation can't fix. Pixel-grid hint geometry
(`#back-shape-<size>`, `#plate-shape-<size>` in `<defs>`) is swapped in per size so small sizes stay crisp
without a second file per icon.

### ADR-004 — Aliases are data
Freedesktop names, legacy names and app ids that should share art live in `src/aliases.json`
(`{"folder": ["inode-directory", "folder-closed"], …}`) and become relative symlinks at build time.

### ADR-005 — Symbolic status icons ship as SVG (exception to ADR-001)
**Context.** The owner asked for top-bar status icons (Wi-Fi, battery, volume…) whose state reads at a glance.
GNOME Shell (St) and GTK recolour `*-symbolic` icons to the panel/foreground colour at runtime; a PNG can't be
recoloured and would break light/dark and accent handling.
**Decision.** `src/status/*-symbolic.svg` (generated by `tools/gen-status.py`) are copied as-is into
`symbolic/status/` (`Type=Scalable`, `Size=16`). They obey what St can recolour: 16×16, filled shapes only,
classes `success|warning|error` only, dimming via group opacity, gaps via clip geometry. Lint enforces it.
**Cost.** State colours are the Shell's (St defaults: success #4e9a06, warning #f5793e, error #cc0000), not ours.
**Amendment (v0.3, KDE).** KDE ignores GTK's `-symbolic` recolouring and would draw these black. Tested with real
GTK 3, GTK 4 and Qt renders: one file works everywhere when paths use `fill="currentColor"` + `ColorScheme-*`
classes and a `current-color-scheme` stylesheet (St/GTK inject `fill: … !important`, which wins; KIconLoader
rewrites the stylesheet, `currentColor` follows). `index.theme` sets `FollowsColorScheme=true`. A fixed
`symbolic/status-22` directory, listed first, carries the same art padded to 22 px for KDE's tray.

### ADR-006 — File types: generated sheet family, drawn labels, per-user MIME add-on
**Context.** The owner's Files showed every JSON as a terminal (`application-json` → `text-x-script`), lock
files, Markdown and certificates as the same grey page (2026-09-20). He chose a symbol + type label at ≥ 48 px
and a tinted-glass-sheet construction (DESIGN §6, §6b).
**Decision.**
1. `tools/gen-mimetypes.py` generates `src/mimetypes/` from two tables — ~30 *categories* (token, symbol,
   pixel hints) × ~130 *types* (GIO icon name → category, label, aliases) — and owns their `aliases.json`
   entries. Names come from `Gio.content_type_get_icon` on real files, not from memory.
2. Labels are **drawn paths** (vector caps ≥ 64, 3 × 5 pixel caps at 48), never `<text>`: resvg renders with
   system fonts off, so output is identical everywhere.
3. Byte-identical renders in one size directory become relative symlinks at build (types in a category are
   identical below 48 px, where the label drops). The size budget moves to **40 MB** (most of it is 256@2x art).
4. A **per-user shared-mime-info package** (`tools/mime/frost.xml` → `~/.local/share/mime/packages/`) gives
   developer files real types — lock files, `.env`, Dockerfile, git files, TS/TSX, PEM keys, SSH public keys,
   `go.mod`/`go.sum`, `.proto`, HCL — and extra globs for stock types (`.jsonc`, `.zsh`, `.sqlite`, `.otf`).
   Weights tie with stock types where content can decide (`.key` vs Keynote, `.pub` vs Publisher) and win only
   where the stock guess is wrong on a developer machine (`.ts` Qt Linguist, `.tsx` Tiled). Every type is a
   sub-class of `text/plain`. Installed/removed by `install:local` (`--no-mime`, `--undo-mime`); verified by
   `tools/mime-probe.py` in a temp `XDG_DATA_HOME`.
**Cost.** A second system touch point (per-user only, owner-approved), and generated SVGs must not be hand-edited.

## index.theme shape (generated)
```ini
[Icon Theme]
Name=Frost
Comment=Frosted-glass icons — clean, minimal
Inherits=Papirus,Adwaita,hicolor
Example=folder
Directories=16x16/places,22x22/places,…          # @1x only
ScaledDirectories=16x16@2x/places,22x22@2x/places,…  # @2x only (spec; Papirus does the same)

[16x16/places]
Size=16
Context=Places
Type=Fixed

[16x16@2x/places]
Size=16
Scale=2
Context=Places
Type=Fixed
```
Contexts used: `places`, `mimetypes`, `apps`, `devices` (lower-case dirs, Title-case `Context=`).
